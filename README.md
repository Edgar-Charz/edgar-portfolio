# Edgar Charles — Portfolio

A responsive portfolio starter built with plain HTML, CSS, and JavaScript. Includes:
- Light/dark mode with saved preference
- Responsive navigation
- Project category filters
- Hero, about, skills, projects, and contact sections

## Run locally
Open `index.html` in your browser. For best results, use VS Code Live Server.

## Before publishing
1. Replace the sample email and social URLs in `index.html`.
2. Add your real profile photo to `assets/images/` and update the hero/avatar markup.
3. Verify project names, descriptions, tech stacks, and links.
4. Create a GitHub repository named `portfolio` (or another name).
5. Upload the files and enable GitHub Pages in **Settings → Pages**.

## Profile photo and CV
- Put your portrait at `assets/images/profile.jpg`; the Home hero shows a circular crop.
- Update `resume.html` with your accurate CV details.
- Add your final PDF at `assets/Edgar-Charles-CV.pdf` for the download button.
- The Resume page includes **Print / Save as PDF** in the browser.


### About slideshow photos
Place `about-1.jpg`, `about-2.jpg`, and `about-3.jpg` in `assets/images/`. Photos fill the slideshow frame with `object-fit: cover`; captions are displayed at the bottom of each photo. Edit each slide's `.photo-caption` text in `index.html` to personalize the captions. The About details now sit in the left column directly below the introduction.
